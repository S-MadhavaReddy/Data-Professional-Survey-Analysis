# Data Professional Survey Analysis | Power BI

## Overview
An interactive Power BI dashboard analyzing survey responses from 630 data professionals to explore job roles, salary trends, programming language preferences, and career satisfaction.

## Key Insights
- Average salary by job title
- Country-wise distribution of survey participants
- Favorite programming languages
- Work-life balance and salary satisfaction
- Perceived difficulty of entering the data industry

## Tools Used
- Power BI
- Power Query
- DAX
- Data Visualization

## Dashboard Features
Interactive KPI cards, bar charts, treemaps, donut charts, gauge visuals, and filters for exploring survey trends.
